# mc-config-demo

Minecraft **サーバーの設定をまるごとGUIで**編集するデモ。「設定ファイルをメモ帳で手編集する地獄」をなくす。

## 何ができる

左でファイルを選ぶと、右がそのファイル専用エディタに切り替わる:

- **server.properties** — 型を理解したフォーム（bool=チェック / 難易度・ゲームモード=ドロップダウン / 数値=スピン）。各設定の **日本語解説** つき（🇯🇵トグル）。mod の有無に関係なく全サーバーが持つファイル。
- **ops.json / whitelist.json** — op・ホワイトリストを **表** で追加/削除/編集（UUID手打ち不要）。バニラ環境の op 管理もここで。
- **config/\*\*/\*.toml** — mod の config（同梱: ATM-8 の Mekanism）。コメント保持フォーム＋検索＋日本語化。

共通機能: 🔎検索 / 🇯🇵日本語解説トグル / 💾保存（書き戻し前に `.bak` を自動作成）

## 起動

```
py editor.py
```

起動すると同梱の `server/` を自動で開く。別フォルダは「📂 サーバーフォルダを開く」から。

## 構成（ミソ：UIとロジックを分離）

- `tomlconf.py` — コメント保持 TOML パーサ
- `propconf.py` — server.properties パーサ ＋ 設定スキーマ（意味/型/選択肢/日本語）
- `playersjson.py` — ops/whitelist 等（オブジェクト配列JSON）の読み書き
- `editor.py` — PySide6 GUI（上記3つを使うだけ）
- `rcon.py` — RCON クライアント（稼働中サーバーへのコマンド送信）
- `server/` — 検証用のサンプルサーバーフォルダ

パーサ3つは UI に依存しないため、サーバー管理ツールのバックエンドなどにそのまま流用できる。

## 工夫した点

- 設定ファイルのコメント・書式を壊さずに読み書きする（3形式とも、読み込んで書き戻すと元ファイルと1バイトも変わらないことを確認済み）
- 保存前に `.bak` を自動作成し、手作業の編集ミスで設定を壊さないようにした
- 各設定項目の型（真偽値・選択肢・数値）を定義し、入力ミスが起きにくいフォームにした
